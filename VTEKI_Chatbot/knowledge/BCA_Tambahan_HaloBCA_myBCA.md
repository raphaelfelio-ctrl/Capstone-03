## Kanal bantuan

### Jam operasional dan kanal Halo BCA

Menurut halaman resmi Halo BCA, layanan Halo BCA tersedia 24 jam setiap hari (24 jam/7 hari) untuk membantu kebutuhan perbankan nasabah.

Kanal resmi Halo BCA:
- Telepon Halo BCA: 1500888
- WhatsApp resmi Bank BCA: 08111500998 (akun terverifikasi)
- Email: halobca@bca.co.id
- Aplikasi haloBCA (telepon via internet, chat, email) dan webchat di bca.co.id

Selalu hubungi kanal resmi dan jangan pernah membagikan data rahasia kepada siapa pun.

Kata kunci: jam operasional 24 jam buka kapan hubungi halo bca setiap hari 7 hari libur malam

## Layanan digital

### Cara reset password BCA ID di myBCA (lupa password)

Menurut Edukatips BCA, jika lupa password BCA ID (untuk login myBCA atau aplikasi haloBCA), nasabah dapat melakukan Reset Password sendiri melalui aplikasi myBCA, myBCA Web, atau aplikasi haloBCA.

Lewat aplikasi myBCA: buka aplikasi myBCA, pilih menu Reset Password, lalu ikuti panduan di layar. Aplikasi akan meminta BCA ID dan nomor kartu ATM, verifikasi identitas, pembuatan password baru, serta verifikasi akhir di dalam aplikasi (verifikasi kode lewat SMS hanya berlaku bagi provider Telkomsel dan XL).

Lewat myBCA Web (mybca.bca.co.id): pilih Reset Password dan ikuti panduan di layar; verifikasi dilakukan di halaman tersebut atau dengan KeyBCA.

Jika BCA ID terblokir, hubungi Halo BCA lebih dulu untuk buka blokir melalui fitur Pusat Bantuan di aplikasi myBCA, aplikasi haloBCA, atau telepon 1500888.

Semua data verifikasi hanya diisi langsung di aplikasi atau situs resmi myBCA, tidak pernah lewat chat. Asisten ini tidak dapat mereset password.

Kata kunci: lupa password kata sandi reset atur ulang mybca bca id login terblokir halobca
